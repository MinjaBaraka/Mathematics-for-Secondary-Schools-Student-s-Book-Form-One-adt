Absolute value of a real number

The absolute value of a real number x, denoted by |x| is the non-negative value of x regardless of its sign. For instance |2|=2 and |−2|=2. Consider the following number line.

The distance from 0 to −2 and that from 0 to 2 is the same, that is 2 units. Thus, 2 is an absolute value of both 2 and −2. The absolute value of a number is the magnitude of that number regardless of its sign.

The absolute value of a number x is written as |x| such that |x|=x if x≥0 and |x|=−x if x<0, and its distance is represented on a number line from 0. This distance is always positive or zero.

For instance; |0.75|=0.75, |−0.143|=0.143, |−12|=12, |0|=0, and |−2|=2.

In general, for any two positive and negative numbers x and −x, their absolute values are equal, that is, |x|=|−x|.

Example 2.19

Evaluate each of the following:

  1. (a) |−2|
  2. (b) |10|
  3. (c) |0|
  4. (d) |8−2|
  5. (e) |−3×6|
  6. (f) |2−6|
  7. (g) |5+2|

Solution

  1. (a) |−2|=2
  2. (b) |10|=10
  3. (c) |0|=0
  4. (d) |8−2|=|6|=6
  5. (e) |−3×6|=|−18|=18
  6. (f) |2−6|=|−4|=4
  7. (g) |5+2|=|7|=7
