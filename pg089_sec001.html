Example 5.16

Find the solution of x+5=8.

Solution

Given x+5=8. Collect the like terms by subtracting 5 from both sides. That is,

x + 5 - 5 = 8 - 5
= 3

Therefore, x=3.

Example 5.17

Find the value of x that satisfies the equation x−8=16−2x.

Solution

Given, x−8=16−2x. Collect the like terms,

x + 2x = 16 + 8
3x = 24

Divide by 3 on both sides,

x=243
= 8

Therefore, x=8.

Example 5.18

Find the value of y if 3y−5=7.

Solution

Given, 3y−5=7.

Add 5 on both sides,

3y - 5 + 5 = 7 + 5
3y = 12

Divide by 3 on both sides,

33y=123
y = 4

Therefore, y=4.

Example 5.19

Solve for the value of x in the equation 3x2+3=12.

Solution

Given 3x2+3=12. Subtract 3 from both sides,

3x2+3−3=12−3
3x2=9

Multiply both sides of the equation by 2 to get,

3x2×2=9×2
3x = 18

Divide by 3 on both sides,

x=183
= 6

Therefore, x=6.
