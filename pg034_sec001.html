Representing real numbers on a number line

Sometimes it is not easy to list all elements of a set of real numbers. For example, it is not possible to list all real numbers which are greater than 12. However, the use of inequality symbols helps to define the elements in the given set. In this case, if x is a real number which is greater than 12, then x>12 defines all the required elements in the set.
