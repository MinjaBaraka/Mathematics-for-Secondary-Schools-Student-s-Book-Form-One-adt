The inequality x>12 means that there are infinitely many real numbers satisfying this condition. Thus, they can be represented on a number line by using an arrow with a small circle at 12 (initial point) since it is not included in the set.

The following number line shows all the real numbers which are greater than 12.

0
12
1
2

Note:

  1. A small circle (o) indicates that the number in a given set of real numbers is excluded in the given set. This is always true for a set of real numbers which involve < or > inequality symbols.
  2. A thick dot (●) indicates that the number in a given set of numbers is included in the given set. This is always true for set of real numbers which involve ≤ or ≥ inequality symbols.
