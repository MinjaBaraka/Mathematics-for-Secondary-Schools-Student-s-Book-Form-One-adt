Example 5.20

Solve for the value of z if 53(3z−2)=10.

Solution

Given, 53(3z−2)=10.

Multiply by 3 on both sides,

3×53(3z−2)=3×10

5(3z−2)=30

Open the brackets,

15z−10=30

15z=40

Divide by 15 on both sides,

z=4015

=83

Therefore, z=83.

Example 5.21

Solve for the value of y, if 83y−2=2.

Solution

Given, 83y−2=2.

Multiply by (3y−2) on both sides,

83y−2×(3y−2)=2(3y−2)

8=2(3y−2)

8=6y−4

12=6y

y=126

=2

Therefore, y=2.

Example 5.22

Find the values of x if |x|=4.

Solution

Given, |x|=4.

Apply the definition of absolute value,

±x=4

Either, +x=4 or −x=4

Therefore, x=4 or x=−4.

Example 5.23

Solve for the value of x if |6−x|=1.

Solution

Given, |6−x|=1.

Apply the definition of absolute value,

±(6−x)=1

Either, +(6−x)=1 or −(6−x)=1.

6−x=1 or −6+x=1

x=5 or x=7

Therefore, x=5 or x=7.
